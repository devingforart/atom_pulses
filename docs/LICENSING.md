# Licencias y distribución

El código propio de este prototipo se marca como `All rights reserved`. Esto evita
conceder accidentalmente derechos de redistribución antes de decidir el modelo de
negocio.

## JUCE

El build del plugin descarga JUCE. Antes de distribuir PULSO hay que elegir y cumplir
una opción compatible con la versión utilizada: licencia comercial de JUCE o los
términos de su licencia open source aplicable. Compilar localmente no convierte este
repositorio en un producto listo para redistribución.

## VST3

La distribución debe cumplir los términos vigentes del SDK VST3 y las reglas de marca
de Steinberg. El plugin no incluye VST2.

## Modelos futuros

Cada modelo tendrá un registro con:

- licencia de código y pesos;
- fuente y licencia del dataset cuando se conozcan;
- restricciones de uso comercial;
- atribución requerida;
- hash exacto del artefacto;
- versión del runtime;
- política sobre outputs y material del usuario.

No debe incorporarse un modelo únicamente porque sus pesos puedan descargarse.
