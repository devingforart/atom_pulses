# PULSO — MIDI wordmark

Custom vector lettering built from five pitch lanes. Each rounded horizontal
segment represents one note; varying note lengths form P, U, L, S and O.
The letters share a compact cap height, aligned stems and consistent spacing.

The original orange waveform remains the symbol to the left. The lettering
uses the theme's ink, with one rust-orange note as an identifiable accent.
There is no background, rainbow palette, piano-roll grid or font dependency.
The wordmark is static: animation is reserved for the composition loader.

Implementation: `web/frontend/src/components/PulsoWordmark.tsx`.
Used by the website and Cloud topbars. Footer and spinner are unchanged.
