# PULSO para Windows x64 — beta sin firma digital

Esta versión se distribuye con un instalador NSIS sin firma digital para evitar costes de certificados durante la beta. Windows SmartScreen puede mostrar una advertencia: verifica que la descarga provenga de la página oficial o de este GitHub Release antes de ejecutarla. El archivo `.sha256` permite comprobar la integridad del instalador.

El instalador incluye PULSO VST3, la aplicación standalone, la documentación y una superficie de control opcional para Ableton Live 12. Cierra Live antes de instalar. Si tienes una instalación antigua creada con Inno Setup, desinstálala primero desde **Aplicaciones instaladas** de Windows; tus ajustes personales no se eliminan.

La alternativa ZIP contiene los mismos componentes y permite una instalación manual. La clave de OpenAI se configura dentro de PULSO y no se distribuye con el instalador.
