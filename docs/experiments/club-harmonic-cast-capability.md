# Club cast capability versus a fixed two-pad floor

The completed cast response for c6f4b68a was rejected because the historical
electronic/hybrid default demanded two sustained harmonic bodies across 85%
of bars. Its primary and secondary bodies existed, but their AI-selected
section availability supported that pair for only 41.67%. This was a cast
permission test, not a measurement of an already written MIDI's harmony.

Explicit Club arrangements now check that their declared primary_chord_bed
is a harmonic_foundation/foundation owner available in at least one actual
macro section. This preserves the existing Club primary-bed commitment without
imposing a second pad, duration quota, fixed entry or continuous tutti. Cast
matrix validation, explicit requested-function contracts, note integrity,
tonal policy and final musical review remain separate and unchanged. Other
behaviors retain their existing floor policy. Explicit functional requests
continue to outrank a default cast suggestion.

The check never adds owners, changes active_sections or writes/fills notes.
Regression tests accept a sparse introduction/outro around one central bed,
reject color-only or unavailable support and verify non-mutation. Passing
cast validation does not by itself establish audible harmonic continuity.
