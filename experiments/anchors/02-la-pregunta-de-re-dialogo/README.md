Anclaje 1. Conservarla para las siguientes pruebas, sin sobrescribir el
Anclaje 1.

- Coste de escritura: 18,7 minutos, unos USD 1,22 estimados; la planificación

Es una referencia auditiva positiva, no una arquitectura aprobada para
producción: el tiempo sigue siendo alto y la auditoría señala que algunos
saltos melódicos no quedan conectados. Comparar siempre escuchando la obra
completa, no por cantidad de notas ni puntuación automática únicamente.
