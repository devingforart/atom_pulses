# Experimento local: hasta 24 voces

El escritor conjunto admite pedidos de 16 a 24 pistas independientes. No impone
un mínimo: la IA conserva la elección del reparto cuando no se especifica.
Planificación, escenas y escritura comparten el reparto ampliado. No se duplican
melodías ni se agregan notas, silencios o rellenos para alcanzar una cantidad.

Hasta 12 voces se conserva la planificación temporal técnica anterior. Por encima,
las ventanas técnicas pasan de 8 a 4 compases en Club, y de 16 a 8 fuera de Club.
Las secciones, frases y escenas siguen siendo las elegidas por la IA y atraviesan
esas ventanas; las voces se escriben juntas y conservan el contexto aceptado.
Esto limita el tamaño de cada respuesta, pero puede aumentar el número de llamadas.

Comparar primero 16 y después 24 voces con el mismo encargo musical. Verificar
identidades independientes, continuidad, protagonismo, cierre, tiempo y coste.
Más capacidad no garantiza mejor composición ni obliga a sonar simultáneamente.
Cloud y saved_1.1 no se actualizan con este experimento.
