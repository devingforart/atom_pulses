# Phrase delivery: local candidate

Baseline: 11f937e3-c795-46bd-9b98-5a44847b052d. The AI created
concrete phrase references but planned a short five-note cue as an eighteen-bar
arc. The final protagonist had 28 notes, the short response 9. This does not by
itself establish quality; user feedback and the plan show why a reference alone
does not guarantee developed phrases.

New plans separate musical speech, continuation, arrival and intentional breath
with an AI-authored phrase_route inside each arc. The AI chooses all lengths,
material and consequences; there is no fixed eight-bar template. Metadata must
cover its own declared span without overlap. Historical plans remain valid.

Before writing each window, a read-only evidence ledger identifies past, current
and future route spans and the actual prior attacks/releases of the named owner.
It excludes future attacks. Counts are evidence, never a density or acceptance
threshold. No code writes notes, fills silence, extends durations or copies a
phrase. No additional API call or deterministic repair is introduced.

Compare a fresh three-minute Club etude with the same prompt, seed and options.
Native tests cover metadata, legacy compatibility, context and immutability.
Completion is not aesthetic success: listen for actual continuation, deliberate
breaths, stable groove and earned closing before promoting this candidate.
