# Local Club preferences

Local UI selects auto / 8-16 / 16-32 / 32-64 bars of preferred layer evolution.
These are editorial preferences, not generated schedules or changes to note grid.
Resource-free checkbox requests the AI choose the principal device rather than
always write an arpeggio. Regular carrier can be bass or chord pulse; existing
cycle contract remains binding for core owners. Phrase-flexible secondary
voices retain freedom. This does not implement multiple rhythmic cells per owner.

Settings persist in job.json and are passed only by the local server as per-job
environment values. Defaults preserve old jobs. Blueprint reuse compares both
preferences. Shared Cloud profile and UI are unchanged. No API call is launched.
Resource variety is enabled in the local form for the user's next experiment,
but old-job reload preserves the original false setting.

Source prompts contain a named local override rather than changing production
rules globally. Effectiveness and whether an arpeggio is actually omitted must
be checked after listening; the checkbox does not procedurally select resources.
